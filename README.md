# houseanalysis — 国创光谷上城 110㎡ 房产：持有还是出售？

基于 80 套真实成交记录（2025-02 至 2026-09）与 2026 年宏微观公开数据，对武汉光谷东「国创光谷上城」一套 110㎡、南北通透、中间楼栋 14/33 层三房做的分析与建议。

**一句话结论：倾向出售（非自住/非唯一住房的前提下）；中性估值约 134 万元，建议挂牌 139–142 万，目标成交 134–137 万，底价约 125 万。** 未来三年房价只要不涨，现在卖出就不吃亏。详见报告。

## 复现

```bash
cd scripts
python3 build_excel.py            # 生成 data/*.xlsx（需 openpyxl；含公式，建议用 LibreOffice/Excel 打开重算）
python3 make_charts.py            # 生成 charts/*.png（需 matplotlib + Noto Sans CJK）
bash build_docx.sh                # Markdown -> Word（需 pandoc）
```

## 说明

- 成交数据来自经纪 App 截图（2026-09-30），原始截图含经纪人水印/个人信息，未纳入仓库。
- 截图之间疑似有遗漏（2025 年 8 月、2026 年 2 月无记录），统计结论存在样本偏差。
- 本仓库内容不构成投资、税务或法律建议。所有假设已在报告附录 B 与 Excel 中标明，可自行修改重算。
